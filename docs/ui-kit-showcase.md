# A22R UI Kit showcase

The UI Kit showcase is a native GPUI surface for checking the reusable A22R
controls, visual tokens, typography, and color-mode behavior. It uses the
pinned `gpui-kit = 0.8.1` family and the bundled Onest font.

![A22R UI Kit showcase in dark mode](<screenshots/Screenshot 2026-11-24 at 22.03.44.png>)

*Figure 1. Dark mode tokens, buttons, selection controls, and feedback states.*

![A22R UI Kit showcase in light mode](<screenshots/Screenshot 2026-11-24 at 22.04.34.png>)

*Figure 2. Light mode autocomplete, multi-select tags, selects, and list rows.*

The showcase is a visual verification surface for shared controls. It is not a
replacement for the item workspace or native end-to-end interaction tests.
The UI Kit dependency and its local maintenance layer are documented in the
[GPUI fork README](../forks/gpui-kit/README.md).
