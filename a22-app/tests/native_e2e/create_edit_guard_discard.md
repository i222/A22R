# Create/edit guard and discard / Создание, guard и отмена

## Русский

Создаёт элемент, открывает редактирование, проверяет сохранение черновика при
Stay, затем отменяет изменения через Discard и подтверждает исходное значение
после перезапуска приложения.

## English

Creates an item, opens editing, verifies that Stay preserves the draft, then
discards the changes and confirms the original value after an application
restart.
