# Accessibility smoke / Проверка Accessibility

## Русский

Проверяет, что главное окно и основные действия приложения видимы в macOS
Accessibility Tree и имеют ожидаемые роли и имена. Затем открывает Inspector
через доступную кнопку и проверяет отдельные окна Inspector и component tree.

## English

Verifies that the main window and primary application actions are exposed in
the macOS Accessibility Tree with the expected roles and names. It then opens
Inspector through its accessible toolbar button and checks the detached
Inspector and component-tree windows.
