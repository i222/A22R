# Unsaved guard save / Сохранение через guard

## Русский

Изменяет существующий элемент, инициирует переход, выбирает Save в диалоге
несохранённых изменений и проверяет новое значение после продолжения и
перезапуска приложения.

## English

Edits an existing item, initiates navigation, chooses Save in the unsaved
changes dialog, and verifies the new value after continuing and restarting the
application.
