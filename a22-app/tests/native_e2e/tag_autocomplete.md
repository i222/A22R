# Tag autocomplete / Автокомплит тегов

## Русский

Создаёт элемент, выбирает дефолтный тег `poc` через Accessibility action
предложения и проверяет наличие тега после перезапуска с той же временной БД.

## English

Creates an item, accepts the default `poc` tag through the suggestion's
Accessibility action, and verifies the tag after restarting with the same
temporary database.
