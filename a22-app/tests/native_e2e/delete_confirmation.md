# Delete confirmation / Подтверждение удаления

## Русский

Проверяет, что удаление не происходит без подтверждения, отмена сохраняет
элемент, а повторное подтверждённое удаление убирает его из списка.

## English

Verifies that deletion does not happen without confirmation, Cancel preserves
the item, and a second confirmed deletion removes it from the list.
